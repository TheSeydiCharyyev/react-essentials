📚 ГЛАВНЫЙ ПРИНЦИП

📚 MAIN PRINCIPLE

Git — программа на вашем компьютере для контроля версий кода (машина времени). GitHub — сайт в интернете для хранения и шаринга Git-репозиториев. Vite — инструмент для создания и запуска React-проектов. Эти три инструмента — база, без которой профессиональная разработка невозможна.
Git — a program on your computer for code version control (time machine). GitHub — a website for storing and sharing Git repositories. Vite — a tool for creating and running React projects. These three are the foundation without which professional development is impossible.

📚 АВТОРИЗАЦИЯ: PERSONAL ACCESS TOKEN

📚 AUTH: PERSONAL ACCESS TOKEN

С 2021 года для push на GitHub нужен Personal Access Token (PAT), а не обычный пароль. Создаётся в Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). Scope: repo. Срок: 90 дней.
Since 2021 pushing to GitHub requires a Personal Access Token (PAT), not a regular password. Created in Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). Scope: repo. Expiration: 90 days.
Мой токен (НЕ ПОКАЗЫВАТЬ НИКОМУ!):

Note (описание): ______________________________

Дата создания: ______________________________

Expires (истекает): ______________________________

Scope: repo (✓)

Сам токен сохранить в менеджер паролей / заметки. В этом конспекте токен НЕ записываем.
My token (NEVER SHARE!):

Note (description): ______________________________

Creation date: ______________________________

Expires: ______________________________

Scope: repo (✓)

Store the token itself in a password manager / notes. In these notes — DON'T write the token.

📚 HOT RELOAD / HMR

📚 HOT RELOAD / HMR

Hot Module Replacement (HMR) — Vite следит за файлами проекта. Когда вы меняете код и сохраняете — Vite перекомпилирует только изменённый модуль и обновляет его в браузере без перезагрузки страницы. Состояние компонентов (например, значение счётчика) сохраняется.
Hot Module Replacement (HMR) — Vite watches project files. When you edit code and save — Vite recompiles only the changed module and updates it in the browser without a page reload. Component state (e.g. counter value) is preserved.
