🎯 LESSON 2.1: GIT + GITHUB ACCOUNT

Задание 2.1: Установить Git, завести GitHub, получить PAT Task 2.1: Install Git, register on GitHub, get a PAT
Лёгкое Easy 45 минут 45 min
Полностью настроить окружение для работы с Git и GitHub — один раз и надолго
Fully set up the environment for working with Git and GitHub — once and for a long time

Условие:

Instructions:

  1. Установить Git:
    • Windows: git-scm.com → Download for Windows → запустить инсталлятор → «Next» с дефолтами. На шаге «default editor» — выбрать VS Code (если установлен).
    • Mac: открыть Terminal → git --version. Если Git не установлен — появится предложение поставить Command Line Tools, согласиться.
  2. Проверить установку:
    • Открыть новый терминал (Git Bash на Windows / Terminal на Mac)
    • git --version — должно показать git version 2.46.x или выше
    • Записать версию в конспект (раздел чеклиста)
  3. Настроить Git (три команды один раз на компьютере): 
    git config --global user.name "Ваше Имя"
git config --global user.email "вашemail@example.com"
git config --global init.defaultBranch main
    Email запомните — тот же вы будете использовать при регистрации на GitHub.
  4. Проверить настройку: 
    git config --global user.name
git config --global user.email
git config --global init.defaultBranch
    Должны вывести три строки с вашими данными.
  5. Зарегистрироваться на GitHub (если аккаунта ещё нет):
    • github.com → Sign up
    • Email тот же, что в git config user.email
    • Username — аккуратный, без цифр-крутостей. Хорошо: imeniaman, maya-dev. Плохо: GAMER_228_XD.
    • Подтвердить email из письма GitHub
    • Plan → Free
  6. Оформить профиль:
    • Settings → Profile
    • Name: ваше реальное имя латиницей
    • Bio: 1-2 предложения, например «Front-end developer learning React. Based in Ashgabat 🇹🇲»
    • Location: ваш город
    • Загрузить аватарку (фото)
    • Сохранить
  7. Создать Personal Access Token (PAT):
    • Settings → пролистать слева вниз до Developer settings
    • Personal access tokens → Tokens (classic)
    • Generate new token → Generate new token (classic)
    • Note: React course — my laptop
    • Expiration: 90 days
    • Scopes: поставить галочку repo (только эту)
    • Generate token
    • СРАЗУ скопировать токен и сохранить в менеджер паролей / защищённые заметки. Больше GitHub не покажет!
  8. Записать в конспект (раздел «Мои данные GitHub»):
    • Username
    • Email
    • Ссылку на профиль: github.com/USERNAME
    • Bio, Location
    • Дату создания токена и дату истечения (90 дней)
    Сам токен в конспект НЕ записывать — только в зашифрованное место.
  1. Install Git:
    • Windows: git-scm.com → Download for Windows → run installer → "Next" defaults. On "default editor" step — pick VS Code (if installed).
    • Mac: open Terminal → git --version. If not installed — a prompt to install Command Line Tools will appear, agree.
  2. Verify install:
    • Open a new terminal (Git Bash on Windows / Terminal on Mac)
    • git --version — should print git version 2.46.x or higher
    • Record version in notes (checklist section)
  3. Configure Git (three commands once per computer): 
    git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
    Remember the email — you'll use the same to register on GitHub.
  4. Verify config: 
    git config --global user.name
git config --global user.email
git config --global init.defaultBranch
    Should print three lines with your data.
  5. Register on GitHub (if you don't have an account):
    • github.com → Sign up
    • Email — the same as in git config user.email
    • Username — clean, no "cool" numbers. Good: imeniaman, maya-dev. Bad: GAMER_228_XD.
    • Verify email from GitHub's letter
    • Plan → Free
  6. Set up profile:
    • Settings → Profile
    • Name: your real name in Latin
    • Bio: 1-2 sentences, e.g. "Front-end developer learning React. Based in Ashgabat 🇹🇲"
    • Location: your city
    • Upload an avatar (photo)
    • Save
  7. Create a Personal Access Token (PAT):
    • Settings → scroll left sidebar to Developer settings
    • Personal access tokens → Tokens (classic)
    • Generate new token → Generate new token (classic)
    • Note: React course — my laptop
    • Expiration: 90 days
    • Scopes: check repo only
    • Generate token
    • IMMEDIATELY copy the token and save in a password manager / secure notes. GitHub won't show it again!
  8. Record in notes (section "My GitHub details"):
    • Username
    • Email
    • Profile URL: github.com/USERNAME
    • Bio, Location
    • Token creation date and expiration date (90 days)
    Don't record the token itself in notes — only in an encrypted place.
Если git --version не работает после установки (Windows):
  1. Закрыть все окна PowerShell / CMD / VS Code
  2. Открыть новый Git Bash: Пуск → «Git Bash»
  3. Если не помогло — перезагрузить компьютер и попробовать снова
  4. Если и это не помогло — переустановить Git, ничего не меняя в инсталляторе
Хранение токена — где сохранить:
  • Менеджер паролей (Bitwarden, 1Password, KeePass) — лучший вариант
  • Заметки на компьютере в защищённом файле (запоминаете пароль)
  • Текстовый файл в папке, НЕ внутри Git-репозитория (и не коммитим!)
  • НЕ отправлять токен в Telegram, Email, Slack — даже себе
If git --version doesn't work after install (Windows):
  1. Close all PowerShell / CMD / VS Code windows
  2. Open a new Git Bash: Start → "Git Bash"
  3. Not working — reboot the computer and try again
  4. Still not — reinstall Git keeping installer defaults
Where to store the token:
  • Password manager (Bitwarden, 1Password, KeePass) — best option
  • Notes on the computer in a protected file (you remember the password)
  • A text file in a folder NOT inside any Git repo (and not committed!)
  • Do NOT send the token via Telegram, Email, Slack — not even to yourself

🎯 LESSON 2.2: FIRST REPO — FROM ZERO TO GITHUB

Задание 2.2: Создать репо, сделать 3 коммита, запушить на GitHub Task 2.2: Create a repo, make 3 commits, push to GitHub
Среднее Medium 45 минут 45 min
Пройти полный жизненный цикл Git от init до push на простом учебном проекте
Go through the full Git life cycle from init to push on a simple practice project

Условие:

Instructions:

  1. Создать папку git-playground на Desktop. Открыть её в VS Code.
  2. Создать файл index.html с минимальным содержимым: 
    <!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Git Playground</title>
</head>
<body>
    <h1>Hello, Git!</h1>
</body>
</html>
  3. Открыть терминал в VS Code (Terminal → New Terminal или Ctrl+` ). Убедитесь, что вы в папке git-playground.
  4. Инициализировать Git и проверить: 
    git init
git status
    Должны увидеть: On branch main и Untracked files: index.html.
  5. Первый коммит: 
    git add index.html
git status                         # файл теперь зелёный
git commit -m "Initial commit: add index.html with hello"
git log                            # видим первый коммит
  6. Создать .gitignore с одной строкой: 
    .DS_Store
    (На Windows этот файл не нужен, но полезно иметь привычку.)
  7. Создать README.md: 
    # Git Playground

A practice repository for Git commands.
Part of React Essentials course — lesson 2.
  8. Второй коммит (уже две строки): 
    git status                         # видно 2 новых файла
git add .                          # добавить всё
git commit -m "Add README and gitignore"
git log --oneline                  # две строки в истории
  9. Изменить index.html: замените <h1>Hello, Git!</h1> на свой вариант, например <h1>Aman учит Git 🚀</h1>. Добавьте <p> с описанием.
  10. Третий коммит: 
    git status                         # видно "modified: index.html"
git diff                           # посмотреть, что изменилось
git add index.html
git commit -m "Update heading with personal touch"
git log --oneline                  # 3 коммита
  11. Создать репо на GitHub:
    • github.com → + → New repository
    • Name: git-playground
    • Description: «Practice repo for Git commands (React course lesson 2)»
    • Visibility: Public
    • Убрать галочки «Add a README» и «Add .gitignore» (они уже есть локально!)
    • Create repository
  12. Привязать и запушить (GitHub показывает команды после создания репо — используйте их или напишите руками): 
    git remote add origin https://github.com/USERNAME/git-playground.git
git push -u origin main
    • Git попросит Username — введите ваш GitHub-логин
    • Git попросит Password — вставьте Personal Access Token из задания 2.1
  13. Проверка на GitHub:
    • Обновить страницу репозитория в браузере
    • Должны увидеть 3 файла: README.md, index.html, .gitignore
    • Кликнуть «3 commits» вверху — увидеть историю трёх коммитов
    • README.md отображается на главной странице репо
  14. Четвёртый коммит + push (отработать рутинный цикл):
    • Добавить в README.md строку с датой: Started on 2026-04-XX
    • В терминале: 
      git add .
git commit -m "Add start date to README"
git push
    • Токен уже закэширован — второй раз спрашивать не будет
    • Обновить страницу репо → увидеть 4-й коммит в истории
  15. Записать URL репо в конспект (раздел «Мои данные GitHub»).
  1. Create folder git-playground on Desktop. Open it in VS Code.
  2. Create file index.html with minimal content: 
    <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Git Playground</title>
</head>
<body>
    <h1>Hello, Git!</h1>
</body>
</html>
  3. Open terminal in VS Code (Terminal → New Terminal or Ctrl+` ). Make sure you're in the git-playground folder.
  4. Initialize Git and check: 
    git init
git status
    Should see: On branch main and Untracked files: index.html.
  5. First commit: 
    git add index.html
git status                         # file is now green
git commit -m "Initial commit: add index.html with hello"
git log                            # see the first commit
  6. Create .gitignore with one line: 
    .DS_Store
    (On Windows not strictly needed, but good habit.)
  7. Create README.md: 
    # Git Playground

A practice repository for Git commands.
Part of React Essentials course — lesson 2.
  8. Second commit (now two lines): 
    git status                         # shows 2 new files
git add .                          # add everything
git commit -m "Add README and gitignore"
git log --oneline                  # two lines in history
  9. Edit index.html: replace <h1>Hello, Git!</h1> with your own, e.g. <h1>Aman learning Git 🚀</h1>. Add a <p> with a description.
  10. Third commit: 
    git status                         # shows "modified: index.html"
git diff                           # see what changed
git add index.html
git commit -m "Update heading with personal touch"
git log --oneline                  # 3 commits
  11. Create repo on GitHub:
    • github.com → + → New repository
    • Name: git-playground
    • Description: "Practice repo for Git commands (React course lesson 2)"
    • Visibility: Public
    • Uncheck "Add a README" and "Add .gitignore" (already exist locally!)
    • Create repository
  12. Link and push (GitHub shows the commands after creating the repo — use them or type by hand): 
    git remote add origin https://github.com/USERNAME/git-playground.git
git push -u origin main
    • Git asks Username — enter your GitHub login
    • Git asks Password — paste the Personal Access Token from task 2.1
  13. Verify on GitHub:
    • Refresh the repo page in the browser
    • Should see 3 files: README.md, index.html, .gitignore
    • Click "3 commits" at the top — see the 3-commit history
    • README.md displays on the repo main page
  14. Fourth commit + push (practice the routine cycle):
    • Add a date line to README.md: Started on 2026-04-XX
    • In terminal: 
      git add .
git commit -m "Add start date to README"
git push
    • Token is already cached — won't ask again
    • Refresh the repo page → see the 4th commit in history
  15. Record the repo URL in notes (section "My GitHub details").
Если push выдаёт ошибку «authentication failed»:
  • Вы вводите пароль от GitHub-аккаунта → замените на PAT
  • Токен истёк (проверить дату Expiration в GitHub settings) → создать новый
  • В Windows может быть старый токен в Credential Manager → Панель управления → Credential Manager → найти git:https://github.com → Remove → запустить push снова
  • На Mac аналогично: Keychain Access → найти github.com → Delete
Если push выдаёт «non-fast-forward» или «rejected»:
  • Значит на GitHub уже есть коммиты (если создали репо с README)
  • Решение: git pull origin main --rebase, потом git push
  • В следующий раз — создавайте репо без README
Если забыли вывести файл из staging: 
git reset HEAD file.html     # убрать из staging, но сохранить изменения
Если нужно отменить последний коммит (не запушенный): 
git reset --soft HEAD~1      # коммит убран, изменения остались в staging
If push shows "authentication failed":
  • You're typing the GitHub account password → replace with PAT
  • Token expired (check Expiration date in GitHub settings) → create a new one
  • On Windows an old token may be in Credential Manager → Control Panel → Credential Manager → find git:https://github.com → Remove → rerun push
  • On Mac similarly: Keychain Access → find github.com → Delete
If push shows "non-fast-forward" or "rejected":
  • There are already commits on GitHub (if you created the repo with README)
  • Fix: git pull origin main --rebase, then git push
  • Next time — create the repo without README
If you need to remove a file from staging: 
git reset HEAD file.html     # unstage but keep changes
If you need to undo the last (unpushed) commit: 
git reset --soft HEAD~1      # commit removed, changes stay in staging

  • Публичный репо git-playground создан на GitHub

  • git push прошёл успешно (авторизация через PAT)
  • Все файлы видны в браузере на GitHub
  • История 4+ коммитов видна на GitHub
  • 4-й коммит («Add start date to README») отправлен без запроса пароля (токен закэширован)
  • URL репо записан в конспект
  • Folder git-playground created and opened in VS Code
  • git init done (.git/ exists)
  • 4+ commits in local history (git log --oneline)
  • Every commit message — verb first, English, no period
  • Public repo git-playground created on GitHub

Создать первый настоящий React-проект, познакомиться со структурой и запушить на GitHub
Create the first real React project, learn its structure and push to GitHub

Условие:

Instructions:

  1. Перейти в папку, где будут жить проекты (терминал): 
    cd ~/Desktop
mkdir -p projects

    npm create vite@latest

    • index.html — единственный HTML

    • src/App.jsx — главный компонент
    • package.json — список зависимостей и scripts

    • Открыть src/App.jsx
    • Найти текст <h1>Vite + React</h1> (ищите через Ctrl+F)
