Задание 1.2: Node.js + VS Code + расширения + Prettier Task 1.2: Node.js + VS Code + extensions + Prettier
Среднее Medium 45 минут 45 min
Подготовить компьютер к разработке React-приложений — все инструменты установлены и настроены
Prep the computer for React dev — all tools installed and configured

Условие:

Instructions:

  1. Установите Node.js LTS:
    • Зайти на nodejs.org
    • Скачать LTS-версию (зелёная кнопка с надписью «LTS»). В 2026 году это Node.js 22.x.
    • Запустить установщик, жать «Next» со всеми дефолтами. На шаге с чекбоксом «Add to PATH» — убедиться, что галочка стоит.
    • На Mac можно через Homebrew: brew install node
  2. Проверка Node.js:
    • Закрыть все открытые терминалы / PowerShell полностью.
    • Открыть новый терминал (Win: PowerShell или CMD, Mac: Terminal).
    • Выполнить node -v — должно вывести v22.x.x (или ваша версия, минимум v20).
    • Выполнить npm -v — должно вывести 10.x.x.
    • Записать версии в конспект (student.html → раздел «Мои инструменты»).
  3. Установите VS Code:
    • code.visualstudio.com → «Download»
    • Запустить установщик, «Next» по дефолту
    • На Windows на шаге с опциями поставьте галочки:
      • «Add Open with Code action to Windows Explorer file context menu»
      • «Add Open with Code action to Windows Explorer directory context menu»
      • «Add to PATH»
      Это даст возможность открывать папку в VS Code правым кликом.
  4. Установите 4 обязательных расширения:
    • Открыть VS Code → Ctrl+Shift+X (Extensions)
    • Найти и поставить: ES7+ React/Redux/React-Native snippets (автор dsznajder)
    • Найти и поставить: Prettier - Code formatter (автор Prettier)
    • Найти и поставить: Auto Rename Tag (автор Jun Han)
    • Найти и поставить: Simple React Snippets (автор burkeholland)
  5. Настройте Prettier как форматтер по умолчанию + Format on Save:
    • Ctrl+, (откроется Settings)
    • В строке поиска вбить format on save → поставить галочку напротив Editor: Format On Save
    • В строке поиска вбить default formatter → выбрать Prettier - Code formatter
  6. Проверка работы Prettier:
    • Создать тестовый файл test.js с корявым форматированием: 
      const x=   1;
function   foo(  a ,b){return a+b;}
    • Нажать Ctrl+S
    • Код должен автоматически превратиться в: 
      const x = 1;
function foo(a, b) {
    return a + b;
}
    • Если форматирования не произошло — проверить настройки из шага 5 ещё раз.
  7. Проверка расширения сниппетов:
    • Создать test.jsx
    • Набрать rafce + нажать Tab
    • Должен автоматически вставиться шаблон компонента: 
      import React from 'react'

function test() {
  return (
    <div>test</div>
  )
}

export default test
    • Если не сработало — перезапустить VS Code.
  8. Отметьте все галочки в чеклисте «Мои инструменты» в конспекте (student.html).
  1. Install Node.js LTS:
    • Go to nodejs.org
    • Download the LTS build (the green "LTS" button). In 2026 it's Node.js 22.x.
    • Run the installer, click "Next" with defaults. On the "Add to PATH" checkbox — make sure it's ticked.
    • On Mac you can use Homebrew: brew install node
  2. Verify Node.js:
    • Close all open terminals / PowerShell completely.
    • Open a new terminal (Win: PowerShell or CMD, Mac: Terminal).
    • Run node -v — should print v22.x.x (or your version, min v20).
    • Run npm -v — should print 10.x.x.
    • Record versions in the notes (student.html → "My tools" section).
  3. Install VS Code:
    • code.visualstudio.com → "Download"
    • Run installer, "Next" defaults
    • On Windows on the options step tick:
      • "Add Open with Code action to Windows Explorer file context menu"
      • "Add Open with Code action to Windows Explorer directory context menu"
      • "Add to PATH"
      This lets you right-click a folder and open it in VS Code.
  4. Install the 4 must-have extensions:
    • Open VS Code → Ctrl+Shift+X (Extensions)
    • Find and install: ES7+ React/Redux/React-Native snippets (by dsznajder)
    • Find and install: Prettier - Code formatter (by Prettier)
    • Find and install: Auto Rename Tag (by Jun Han)
    • Find and install: Simple React Snippets (by burkeholland)
  5. Set Prettier as default formatter + Format on Save:
    • Ctrl+, (opens Settings)
    • Search format on save → check Editor: Format On Save
    • Search default formatter → pick Prettier - Code formatter
  6. Verify Prettier works:
    • Create a test file test.js with ugly formatting: 
      const x=   1;
function   foo(  a ,b){return a+b;}
    • Press Ctrl+S
    • Code should auto-reformat to: 
      const x = 1;
function foo(a, b) {
    return a + b;
}
    • If no formatting happens — re-check settings from step 5.
  7. Verify snippets extension:
    • Create test.jsx
    • Type rafce and hit Tab

function test() {
  return (
    <div>test</div>
  )
}

  1. Полностью закрыть PowerShell / CMD / VS Code
  2. Открыть новый PowerShell (Win + R → powershell → Enter)
  3. Если всё равно не работает — перезагрузить компьютер
  4. Если и это не помогло — переустановить Node, не забыв галочку «Add to PATH»

Задание 1.3: Hello, React! — три компонента в одном файле Task 1.3: Hello, React! — three components in one file
Среднее Medium 45 минут 45 min
Написать первое настоящее React-приложение без npm и без сборки — прямо в HTML-файле
Write your first real React app without npm and without a build — right in an HTML file

Условие:

Instructions:

  1. Создать папку react-lesson-1 в любом удобном месте (например, на рабочем столе).
  2. Открыть папку в VS Code: правый клик по папке → «Open with Code» (если добавили опцию при установке). Или: VS Code → File → Open Folder → выбрать папку.
  3. Создать файл index.html внутри папки. Вставить шаблон-заготовку из подсказки ниже.
  4. Написать 3 компонента:
    • Hello — возвращает <h1>Привет, React!</h1>
    • About — возвращает <p> с одним предложением о себе (ваше имя, возраст, город)
    • Footer — возвращает <footer> с текущим годом и вашим именем (вручную, через обычный HTML)
  5. Отрендерить все 3 компонента внутри одного <div>: 
    root.render(
    <div>
        <Hello />
        <About />
        <Footer />
    </div>
);
  6. Открыть index.html двойным кликом (или правый клик → «Open with» → Chrome). Должны увидеть все 3 блока на странице.
  7. Проверить через React DevTools (F12 → Components). В дереве должно быть: 
    Hello
About
Footer
    Кликните на Hello — справа увидите информацию о нём. Это первый раз, когда вы смотрите на свой React-код «изнутри».
  8. Стили: добавить в <head> тег <style> и покрасить заголовок. Например: 
    <style>
    body { font-family: Arial, sans-serif; padding: 20px; }
    h1 { color: #3b82f6; }
    footer { margin-top: 40px; color: #94a3b8; font-size: 14px; }
</style>
  9. Сделать скриншот итоговой страницы в браузере. Это ваш первый React-артефакт — сохраните его, он вам будет дорог :)
  1. Create a folder react-lesson-1 in any convenient place (e.g. the Desktop).
  2. Open the folder in VS Code: right-click the folder → "Open with Code" (if you added the option during install). Or: VS Code → File → Open Folder → pick it.
  3. Create a file index.html inside the folder. Paste the template from the hint below.
  4. Write 3 components:
    • Hello — returns <h1>Hello, React!</h1>
    • About — returns a <p> with one sentence about you (name, age, city)
    • Footer — returns a <footer> with the current year and your name (manually typed)
  5. Render all 3 components inside a single <div>: 
    root.render(
    <div>
        <Hello />
        <About />
        <Footer />
    </div>
);
  6. Open index.html with a double click (or right-click → "Open with" → Chrome). You should see all 3 blocks on the page.
  7. Inspect via React DevTools (F12 → Components). The tree should show: 
    Hello
About
Footer
    Click Hello — on the right you'll see info about it. First time you look at your React code "from the inside".
  8. Styling: add a <style> block in <head> and color the heading. Example: 
    <style>
    body { font-family: Arial, sans-serif; padding: 20px; }
    h1 { color: #3b82f6; }
    footer { margin-top: 40px; color: #94a3b8; font-size: 14px; }
</style>
  9. Screenshot the final page in the browser. Your first React artifact — save it, it'll mean something to you later :)
Полный шаблон index.html — копируйте и адаптируйте: 
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>My First React App</title>
    <style>
        body { font-family: Arial, sans-serif; padding: 20px; }
        h1 { color: #3b82f6; }
        footer { margin-top: 40px; color: #94a3b8; font-size: 14px; }
    </style>
</head>
<body>
    <div id="root"></div>

    <script crossorigin src="https://unpkg.com/react@19/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@19/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>

    <script type="text/babel">
        function Hello() {
            return <h1>Привет, React!</h1>;
        }

        function About() {
            return (
                <p>
                    Меня зовут [Имя], мне [возраст] лет,
                    я учусь React в [город].
                </p>
            );
        }

        function Footer() {
            return (
                <footer>
                    © 2026 — [Ваше имя]. Сделано на первом занятии React Essentials.
                </footer>
            );
        }

        const root = ReactDOM.createRoot(document.getElementById('root'));
        root.render(
            <div>
                <Hello />
                <About />
                <Footer />
            </div>
        );
    </script>
</body>
</html>
Если страница пустая:

  • Самые частые ошибки: забыт type="text/babel", опечатка в тегах, лишние скобки в JSX.
  • Компонент должен начинаться с большой буквы (function Hello(), не function hello()).

            <Bio />
            <Skills />
            <SocialLinks />
            <ContactBtn />
            <Footer />

}
Внимание к JSX:
  • В JSX пишется className, а не class (class — зарезервированное слово в JS)
  • Все теги должны закрываться, даже одиночные: <br />, <img ... />, <hr />
  • Компонент может возвращать только ОДИН корневой элемент — оберните в <div>, если нужно несколько
