📚 ГЛАВНЫЙ ПРИНЦИП

📚 MAIN PRINCIPLE

React — это JavaScript-библиотека для построения UI из компонентов. Вы описываете «что должно быть на экране», а React сам обновляет DOM. Это называется декларативный подход. Главная идея — компоненты (переиспользуемые кусочки интерфейса, как LEGO).
React is a JavaScript library for building UIs from components. You describe "what should be on screen", and React updates the DOM itself. This is the declarative approach. The main idea is components (reusable UI pieces, like LEGO).

📚 КОМПОНЕНТЫ — СЕРДЦЕ REACT

📚 COMPONENTS — THE HEART OF REACT

Компонент — самостоятельный кусок UI, который можно переиспользовать. Кнопка, карточка, меню, вся страница — всё компоненты. В коде — обычная JS-функция, которая возвращает JSX.
Component — a self-contained piece of UI you can reuse. Button, card, menu, the whole page — all components. In code — a regular JS function that returns JSX. 
function Hello() {
    return <h1>Привет, React!</h1>;
}
Что даёт компонентный подход: переиспользование, изоляция, читаемость, работа в команде, тестируемость.
What components give you: reuse, isolation, readability, teamwork, testability.

📚 ВИРТУАЛЬНЫЙ DOM

📚 VIRTUAL DOM

Виртуальный DOM — «черновик» настоящего DOM в памяти JavaScript. React делает все расчёты в черновике (это быстро и дёшево), сравнивает старый и новый варианты (diffing), и обновляет в настоящем DOM только то, что реально изменилось.
Virtual DOM — a "draft" of the real DOM in JavaScript memory. React runs all calculations in the draft (fast and cheap), compares old and new versions (diffing), and updates in the real DOM only what actually changed. 
Клик → данные меняются → виртуальный DOM пересчитывается
     → сравнение со старым → обновление ТОЛЬКО изменённого

📚 ПЕРВЫЙ REACT ЧЕРЕЗ CDN

📚 FIRST REACT VIA CDN

Быстрый способ запустить React без npm и Vite — для первого опыта. В реальных проектах используем Vite (занятие 2).
Fast way to run React without npm and Vite — for a first experience. In real projects use Vite (lesson 2). 
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>My First React</title>
</head>
<body>
    <div id="root"></div>

    <script crossorigin src="https://unpkg.com/react@19/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@19/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>

    <script type="text/babel">
        function Hello() {
            return <h1>Привет, React!</h1>;
        }

        const root = ReactDOM.createRoot(document.getElementById('root'));
        root.render(<Hello />);
    </script>
</body>
</html>
Не забудьте type="text/babel" в последнем <script>. Без него браузер не поймёт JSX → ошибка.
Don't forget type="text/babel" on the last <script>. Without it the browser can't parse JSX → error.
